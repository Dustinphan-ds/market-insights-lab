# Market Insights Lab 

A student-led project using Python and machine learning to analyze
financial markets and support investment research.

> Educational project only — not financial advice.

## Goals
- Pull and clean real market data (stock prices, economic indicators, SEC filings)
- Explore returns, risk, and relationships between assets
- Test simple ML models *honestly* (avoiding overfitting and look-ahead bias)
- Communicate findings clearly to non-technical audiences

## Tools
Python · pandas · matplotlib · yfinance · FRED · SEC EDGAR · Google Colab · GitHub
